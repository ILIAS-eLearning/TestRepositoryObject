This is an example Plugin with minimal features for the Repository Object Plugin Slot.

## Installation 

```
mkdir -p public/Customizing/global/plugins/Services/Repository/RepositoryObject
cd public/Customizing/global/plugins/Services/Repository/RepositoryObject
git clone --branch release_12 https://github.com/ILIAS-eLearning/TestRepositoryObject.git
```
